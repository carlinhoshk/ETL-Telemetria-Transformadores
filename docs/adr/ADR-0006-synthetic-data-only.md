# ADR-0006: Synthetic data only

- Status: accepted
- Date: 2026-08-12

## Context

The project emulates industrial transformer monitoring. Using real data from
manufacturers or utilities would raise confidentiality and licensing issues,
and the portfolio does not need it.

## Decision

All data is synthetic and clearly labeled:

- Transformer design/project data: plausible, generator-created values
  (never real manufacturer data).
- Telemetry: generated by the Go simulator with physics-plausible
  relationships (load → temperatures, ambient → oil), not pure randomness.
- ML models are trained only on this synthetic data.

The synthetic disclaimer is present in the README and every place data is
described.

## Consequences

- No risk of leaking proprietary information.
- The simulator must be credible enough to produce useful ML outcomes.
- Public Siemens Energy documentation is used only for inspiration and
  mapping (`docs/siemens-emulation.md`), never copied as proprietary specs.
